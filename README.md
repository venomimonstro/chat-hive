# CHAT Hive

CHAT is a mobile-first social messenger focused on fast communication, social discovery, creator growth and reliable operation on poor networks.

## Status

Development has started from the approved master specification.

- Current phase: Phase 0/1 — Product, Security and Technical Foundation
- Source of truth: `docs/MASTER_PLAN.md`
- Architecture: modular monolith + realtime gateway + asynchronous workers
- Backend: Go
- Frontend: Next.js + TypeScript
- Data: PostgreSQL, Redis, NATS JetStream

## Local development

The repository is being bootstrapped in Sprint 00–01. See `docs/MASTER_PLAN.md` for the authoritative sprint status and acceptance criteria.
